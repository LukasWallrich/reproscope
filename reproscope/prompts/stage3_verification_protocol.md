Computational verification protocol (takes precedence over historical statements about reference-adapter availability):

Every specification must pass independent checks of the estimate, retained participant identities, every emitted standard error and confidence interval, raw p-value and multiplicity calculation. The independent reference translates screened methods from the blind contract and grid without seeing your code, plan or outputs. Unsupported or incomplete verification blocks acceptance; do not suppress an output or relabel a method to evade a check.

For deterministic seeded verification, use numpy.random.default_rng with the screened seed. Draw bootstrap participant indices with rng.integers(0,n,size=(B,n)), preserving original retained row order. Batching may divide rows of this matrix without changing the random stream. Draw sign flips as 2*rng.integers(0,2,size=(B,n))-1. Freedman–Lane draws call rng.permutation(reduced_model_residuals) independently once per draw. Do not use legacy RandomState. Use linear empirical quantiles. For BCa use the midpoint tie convention for bias correction and participant jackknife acceleration, as in scipy.stats.bootstrap(method='BCa'). These are fixed computational conventions, not multiverse dimensions. A pre-existing seeded implementation can be migrated through verified source repair without changing the screened scientific choices.

Keep original data scoring and any prespecified outlier screen outside bootstrap/permutation draws, then refit and re-rank within each draw where specified. Preserve paired observations and the screened nuisance design. Declare exact realised included_ids in every plan when a unique identifier is deposited, even when the legacy direct-column adapter labels the method unsupported.

Use p_adjustment='fixed_threshold', per_test_alpha=<source per-comparison criterion>, p_family=[] and p=min(1,p_raw*.05/per_test_alpha) when the screened source criterion is a fixed threshold. This is threshold-equivalent rescaling for display against .05, not an inferred family size or a recovered family of p-values. Do not invent nonfocal p-values. For Holm, compute each nonfocal test from its own screened binding and include plan.nonfocal_family_bindings=[{file,x,y,alternative},...] alongside the actual p_family. Only supported, source-bound nonfocal tests may enter that family.

Distinguish the two supported trimming methods. Paired-Yuen uses separately trimmed marginal means and their paired winsorised covariance. A screened trimmed mean of within-pair differences instead trims those differences, using their winsorised variance divided by the effective-sample correction h*(h-1)/(n-1), with h=n-2*floor(trim*n) and df=h-1. Follow the screened method explicitly; these formulas are not interchangeable. Report the exact estimator even when several raw-unit location estimators share one effect curve. If a log scale is selected, verify positivity and log each condition before computing differences or applying the selected outlier rule. Rank-biserial, rank association and semipartial outputs keep their distinct method and null labels. Quantify finite Monte Carlo resolution and uncertainty; computational agreement does not remove sampling or model assumptions.

For Wilcoxon signed-rank inference, honour an explicitly screened exact-no-ties method: verify nonzero untied differences and use method="exact"; inputs outside that domain must be declared unavailable. Otherwise use scipy.stats.wilcoxon(method="auto", zero_method="wilcox", correction=True) with the selected alternative. This applies the documented exact/permutation/normal policy to the observed ties and zeros. Do not impose a legacy n<=25 exact-test cutoff; tie-free samples up to 50 are exactly supported. For resampling-heavy grids, batch participant resamples and use NumPy linear algebra (for example batched QR projections and scipy.stats.rankdata along the participant axis) rather than fitting a Python model object separately for every draw. For internally studentized residual trimming, round the maximum absolute score to 12 decimal places before stable descending sorting, then break ties by original deposited row order. This numerical tie convention prevents different linear-algebra implementations selecting different copies of identical participant rows in private resamples.
