# Specification curves and report clarity

The report now combines an estimate/interval curve with an aligned analytical-choice matrix. A same-scale reported estimate appears as a dashed reference line with a rounding band and explicit lower/tied/higher counts. The interactive figure and a standard R/specr SVG export use the same verified aggregate results. Inference-only choices remain visible; specifications are not independent votes.

For the published Hurst v1 Pearson curve, the reported −0.51 has four specifications below its rounding range, four agreeing at two printed decimal places, and sixteen above that range. The four ties occupy positions 5–8 of 24. The rank-correlation group has no Pearson reference. Petersen's reported standardised effect is not placed on raw differences, log ratios or rank-biserial effects. A reported value does not identify a recovered author specification; unknown author choices remain unknown.

Both requested reviews were completed: [Fable](fable_clarity_review.md) and an [independent subagent](independent_clarity_review.md). | Finding | Pipeline response |
|---|---|
| Interpretation and evidence tables disagreed about active decisions | Both now decode specifications through the canonical grid-level parser. Output labels such as `ci_method` cannot replace analytical factor levels. A regression verifies unchanged estimates/p-values under interval-only choices and changed p-values under test choices. |
| Correlation described as subtraction | The method context now distinguishes association from paired differences and comes from independently verified recipes. |
| Reported estimate absent from the interactive curve | Each group receives a typed, group-specific reference, with precision-aware position counts. The browser retains the reference while selecting specifications. |
| Repeated source/diagnosis prose | Identical detailed diagnoses are deduplicated within topics; self-quoting explanations and internal JSON excerpts are suppressed. Full source quantities remain searchable and linked. Statistical-review reasoning is expandable and links to overlapping discrepancy evidence. |
| Screening revision history presented as current methods | Screening text is explicitly an audit; the specification inspector states the combined method actually executed. Generic irrelevant method caveats are removed. |
| Ambiguous duty accounting and stale failure banner | The overview distinguishes pending computation dispositions from unresolved causes. A retry clears its previous failure before rendering; actual failures include their stated reason. |
| Tiny negative values falsely flagged for opposite signs | The sign check uses unrounded values. Exact zero has no asserted sign. |
| Close-agreement labels contradicted precision diagnoses | The report uses the same deterministic discrepancy predicate as the diagnosis inventory. |
| F degrees-of-freedom comparisons were malformed | Ambiguous one-number F notation is flagged, not auto-split. A valid numerator/denominator pair is not compared with a residual-df scalar. Missing independent numerator evidence remains explicit. |
| Paired raw signed differences looked like large errors | Comparison differences use the declared magnitude convention when applicable; raw results and replica-specific method orientation remain available. |
| Unsupported permanent retention history | Editorial validation rejects claims that absent records were never retained or collected; copy must describe what the supplied deposit contains. |

Some review suggestions were not adopted. The source PDF itself prints `F(5132)`, so an extraction-loss explanation is not established. Monte Carlo minimum attainable p-values are not automatically upper bounds on the underlying tail probability. Inference variants are genuine analytical choices and remain separate columns. Missing author choices are not inferred by picking the estimate closest to publication. Correlated likelihood-ratio residuals and alternative coding hypotheses warrant further diagnosis but do not establish a corrupt input column or an original scoring convention; those are not promoted to demonstrated paper errors.
