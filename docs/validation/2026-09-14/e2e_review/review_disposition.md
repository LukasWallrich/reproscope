## Review provenance and implementation checkpoints

The following chronological record preserves earlier decisions, failures and checkpoint statuses. Earlier pending statements and test totals describe those checkpoints; they are superseded by the current validation record above.

The structured Claude review identified problems in effect-scale references, per-specification scope validation, verification-aware agreement counts, generator provenance, partial-report handling and inference-factor summaries. These are implemented in the common pipeline and report renderer. The original review is [recorded here](claude_fable_review.json).

- Effect references and curve ranks use the same metric and effect group; absent same-scale reported values are explicitly unavailable.
- Test statistics and p-values cannot be primary effect-scale metrics. Screened reporting contracts govern each CSV row. Ratio metrics use a null value of one.
- Close-agreement replica counts require an accepted audit and independently verified method. Descriptive agreement and conventional reconstruction agreement have separate labels.
- Ordinary and scoped multiverse generators have explicit provenance. Validation requires the ordinary generator.
- A failed citation repair quarantines unsupported proposed findings and qualifies the review. It cannot establish an error. A failed pipeline stage retains a partial report and its failure reason.
- Factor summaries show matched changes in point estimates, p-values within the same null group, and interval widths. Execution sampling retains all screened dimensions.
