The model-free preflight is:

```sh
.venv/bin/python -m reproscope.validation --out /private/tmp/reproscope-preflight.json
```

It returns a nonzero status when artifacts are stale or analytical acceptance is unresolved. The evaluation writeup carries this status instead of presenting old outputs as validation of current code. Failed executions can be completed evaluation outcomes, but still count against planned-attempt success.

For the current cohort, preflight identifies stale stage artifacts, missing versioned packet audits, unresolved analytical audits and executions that predate the result contract. The original outputs and generated evaluation documents remain intact. Start a fresh run version when rebuilding intake, because claim identifiers and the blind task can change. Generation invalidation archives existing replica and executor work rather than deleting it.

Validation: 291 offline tests pass; 14 environment/fixture-dependent tests are skipped and one slow test is deselected by the repository defaults. Python compilation and whitespace checks pass.

The offline regression suite covers no-op scripts, changes to individual statistical fields, hardcoded outputs that initially match, wrong variance methods, dishonest execution plans, equivalent branches, rejected author references, ambiguous focal/sample binding, inference contracts, cache integrity and planned-attempt denominators. A correct synthetic unequal-group analysis passes fresh execution, independent calculation and perturbation; each deliberately incorrect variant fails. Before claiming pipeline validity, collect an independently annotated intake set covering multiple studies, derived/reversed variables, ambiguous exclusions, repeated numerical values and partial deposits. Score extraction recall and binding precision/recall separately. Freeze implementation and cohort choices before held-out runs. Synthetic regressions establish the specified software behaviour; they cannot establish intake accuracy, reliable interpretation of source quotations, or generalisation.
