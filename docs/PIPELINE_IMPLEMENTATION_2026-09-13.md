# Pipeline integrity implementation and validation (v4 evidence)

Current development evidence and controls across all 15 problem areas are documented in [the v5 acceptance account](LIVE_INTEGRATION_V5_2026-09-14.md). This dated account describes the frozen v4 run.

The pipeline now rejects unresolved source targets before generation or grading, uses explicit quantity and analysis identities, and separates numerical agreement from source and method verification. The known missed-pair and comparator defects have regression coverage. A passing execution check cannot finalise the historical Petersen run under the new semantic checks.

These changes add implementation controls across all 15 areas in the [quality plan](PIPELINE_IMPROVEMENT_PLAN_2026-09-13.md). They do **not** establish a new extraction accuracy figure. The fresh development run also has 57.1% candidate pairing, with 62 transcription agreements among 68 pairs and no exact agreement across all semantic fields. This remains inadequate evidence of extraction quality. Source gates admit 99 of 166 records and exclude 67; exclusion prevents unsupported grading but does not establish improved source accuracy. Independent source annotation remains required.
